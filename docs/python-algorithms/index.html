  4. 시간복잡도를 표로 정리합니다연산마다 얼마나 빠른지, 왜 그런지를 한눈에 비교합니다.
  5. 대표 문제를 풉니다접근 방법과 풀이는 접혀 있습니다. 먼저 스스로 생각해 본 뒤 펼쳐 보세요.
  6. 스스로 확인하고 정리합니다질문에 답해 보고, 마지막 정리 목록으로 장 전체를 다시 훑습니다.
