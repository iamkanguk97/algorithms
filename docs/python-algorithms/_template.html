이 장에서 배울 것

  • 스택이 왜 "나중에 넣은 것을 먼저 꺼내는" 구조인지 설명할 수 있다
  • 파이썬 리스트로 push, pop, peek을 쓸 수 있다
  • 스택 연산의 시간복잡도와, 리스트를 잘못 써서 느려지는 경우를 안다
  • 괄호 짝 맞추기 문제를 스택으로 풀 수 있다

스택이란

핵심

스택은 마지막에 넣은 것이 가장 먼저 나오는 자료구조다. 이 성질을 LIFO(Last In, First Out)라고 부른다.

식당에서 접시를 쌓는 모습을 떠올리면 쉽다. 새 접시는 맨 위에 올리고, 꺼낼 때도 맨 위부터 집는다. 가운데 접시를 빼려면 그 위의 접시를 모두 먼저 치워야 한다.

그래서 스택이 하는 일은 사실상 세 가지뿐이다.

  • push — 맨 위에 넣는다
  • pop — 맨 위에서 꺼낸다
  • peek — 꺼내지 않고 맨 위만 본다

파이썬 리스트로 스택 쓰기

파이썬에는 스택 전용 자료형이 따로 없다. 리스트의 끝을 스택의 맨 위로 삼으면 그대로 스택이 된다.


stack = []

stack.append(1)        # push
stack.append(2)
stack.append(3)
print(stack)

top = stack[-1]        # peek: 꺼내지 않고 맨 위만 본다
print(top)

print(stack.pop())     # pop: 맨 위를 꺼낸다
print(stack)
print(len(stack) == 0) # 비었는지 확인

연산별 시간복잡도

스택 연산은 모두 리스트의 끝에서만 일어난다. 끝에서 넣고 빼면 다른 원소를 옮길 필요가 없어서, 원소가 몇 개든 거의 같은 시간이 걸린다.

자주 하는 실수

빈 스택에서 꺼내기

빈 리스트에 pop()을 하면 IndexError: pop from empty list가 난다. stack[-1]도 마찬가지로 에러가 난다. 꺼내기 전에 if stack:으로 확인한다.

pop(0)으로 순서 뒤집기

pop(0)은 맨 앞을 꺼내므로 스택이 아니라 큐처럼 동작하고, 매번 O(n)이 걸린다. 먼저 넣은 것을 먼저 꺼내야 한다면 collections.deque의 popleft()를 쓴다. 11장에서 다룬다.

대표 문제

Problem쉬움스택

괄호 짝 맞추기

괄호 ( ) [ ] { }로만 이루어진 문자열 s가 주어진다. 모든 괄호가 올바른 순서로 닫히면 True, 아니면 False를 돌려주는 함수를 작성하라.

입력출력이유
"([]{})"True안쪽부터 차례로 닫힌다
"([)]"False[가 닫히기 전에 )가 온다
"(("False닫히지 않은 괄호가 남는다
접근 방법먼저 생각해 보고 펼치세요

닫는 괄호는 언제나 가장 최근에 연 괄호와 짝이 맞아야 한다. "가장 최근 것부터 처리"는 정확히 스택이 하는 일이다.

  1. 여는 괄호를 만나면 스택에 넣는다.
  2. 닫는 괄호를 만나면 스택에서 하나 꺼내 짝이 맞는지 본다. 스택이 비어 있거나 짝이 다르면 바로 실패다.
  3. 끝까지 읽은 뒤 스택이 비어 있어야 성공이다.
풀이 코드 

def is_valid(s: str) -> bool:
    pairs = {')': '(', ']': '[', '}': '{'}
    stack = []

    for ch in s:
        if ch in pairs:                       # 닫는 괄호
            if not stack or stack.pop() != pairs[ch]:
                return False
        else:                                 # 여는 괄호
            stack.append(ch)

    return not stack                          # 남은 괄호가 없어야 한다


print(is_valid("([]{})"))
print(is_valid("([)]"))
print(is_valid("(("))

스스로 확인

리스트로 스택을 만들 때, 리스트의 앞이 아니라 끝을 맨 위로 삼는 이유는?

끝에서 넣고 빼면 다른 원소를 옮기지 않아 O(1)이다. 앞을 맨 위로 삼으면 insert(0, x)와 pop(0)이 매번 나머지 원소를 모두 옮겨 O(n)이 된다.

"(()"를 is_valid에 넣으면 어디에서 False가 결정되는가?

반복문 안에서는 실패하지 않는다. 문자열을 다 읽은 뒤 스택에 (가 하나 남아 있어서, 마지막 return not stack이 False를 돌려준다.

빈 스택에서 stack[-1]로 peek하면 어떻게 되는가?

IndexError: list index out of range가 난다. pop과 마찬가지로 먼저 비었는지 확인해야 한다.

정리

  1. 스택은 마지막에 넣은 것을 먼저 꺼내는 LIFO 구조다.
  2. 파이썬에서는 리스트의 끝을 맨 위로 삼아 append, pop, [-1]로 쓴다.
  3. push, pop, peek은 모두 O(1)이다. pop(0)은 O(n)이니, 앞에서 꺼내야 하면 deque를 쓴다.
  4. "가장 최근 것과 짝을 맞추는" 문제(괄호 검사, 되돌리기 등)를 만나면 스택을 먼저 떠올린다.
