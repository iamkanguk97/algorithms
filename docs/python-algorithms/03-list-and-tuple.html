리스트와 튜플

여러 값을 순서대로 담는 리스트는 코딩 테스트에서 가장 많이 쓰는 자료형입니다. 리스트를 자르고, 고치고, 정렬하는 법과 함께 바꿀 수 없는 짝꿍인 튜플을 익힙니다.

인덱싱 · 슬라이싱컴프리헨션sort · sorted튜플 · 언패킹

이 장에서 배울 것

  • 인덱스와 슬라이싱으로 리스트에서 원하는 부분을 꺼낼 수 있다
  • 리스트 메서드마다 걸리는 시간이 다른 이유를 설명할 수 있다
  • 리스트 컴프리헨션과 2차원 리스트를 함정 없이 만들 수 있다
  • 튜플 언패킹, enumerate, zip으로 반복문을 짧게 쓸 수 있다
  • key를 써서 여러 기준으로 정렬할 수 있다

리스트 만들기와 인덱싱

핵심

리스트는 값을 순서대로 늘어놓고 번호로 바로 찾아가는 자료형이다. 번호는 0부터 센다.

리스트는 대괄호 안에 값을 쉼표로 늘어놓아 만든다. 각 칸의 번호를 인덱스(index)라고 한다. 인덱스는 "맨 앞에서 몇 칸 떨어져 있는가"를 뜻해서 첫 칸이 0번이다.

음수 인덱스는 뒤에서부터 센다. -1은 마지막 칸, -2는 그 앞 칸이다. 내부에서는 음수 i를 len(a) + i로 바꿔 찾아간다.


nums = [10, 20, 30, 40, 50]

print(list(range(5)))      # range를 리스트로 펼친다
print([0] * 4)             # 0으로 채운 4칸짜리 리스트
print(nums[0], nums[-1])   # 첫 칸, 마지막 칸
nums[1] = 99               # 칸의 값을 바꿀 수 있다
print(nums, len(nums))

[0, 1, 2, 3, 4]
[0, 0, 0, 0]
10 50
[10, 99, 30, 40, 50] 5

인덱스로 읽고 쓰는 일은 리스트가 얼마나 길든 O(1)이다. 칸들이 메모리에 나란히 놓여 있어서 "시작 위치 + 칸 크기 × 인덱스"로 위치를 바로 계산하기 때문이다(8장). 없는 칸을 읽으면 IndexError: list index out of range가 난다.

[0] * n은 방문 표시나 개수 세기용 배열에 자주 쓴다. 단, 2차원에서는 함정이 있다(2차원 리스트 절).

슬라이싱

슬라이싱(slicing)은 리스트의 한 구간을 잘라 새 리스트로 만드는 문법이다. a[start:stop:step]처럼 쓰고, start 칸은 들어가고 stop 칸은 들어가지 않는다.

start를 빼면 처음부터, stop을 빼면 끝까지, step을 빼면 한 칸씩이다. step이 음수면 뒤에서 앞으로 걷는다. 이때 start와 stop을 빼면 끝에서 처음까지라는 뜻이 되어 a[::-1]이 뒤집힌 리스트가 된다.


a = [10, 20, 30, 40, 50]

print(a[1:4])     # 1, 2, 3번 칸 (4번은 빠진다)
print(a[3:])      # 3번 칸부터 끝까지
print(a[::2])     # 두 칸씩 건너뛰며
print(a[-2:])     # 뒤에서 두 개
print(a[::-1])    # 거꾸로
print(a[1:100])   # 범위를 넘어도 에러가 나지 않는다

[20, 30, 40]
[40, 50]
[10, 30, 50]
[40, 50]
[50, 40, 30, 20, 10]
[20, 30, 40, 50]

인덱싱과 달리 슬라이싱은 범위를 벗어나도 있는 칸까지만 잘라 준다. 그리고 결과는 원본의 일부를 가리키는 것이 아니라 새 리스트다. 그래서 a[:]는 전체 복사가 되고, 잘라 낸 길이 k만큼 O(k)가 걸린다. 반면 b = a는 복사가 아니라 같은 리스트에 이름을 하나 더 붙이는 것이다(2장).

stop 칸을 빼는 이유

그래야 a[:k] + a[k:]가 겹치거나 빠지는 칸 없이 정확히 원래 리스트가 된다. 잘라 낸 길이도 stop - start로 바로 나온다.

리스트 메서드와 시간복잡도

메서드는 이름과 함께 리스트의 어디에서 일어나는 연산인지를 기억해야 한다. 같은 "넣기"라도 끝에서 하느냐 앞에서 하느냐에 따라 속도가 크게 다르다.


a = [3, 1, 4]

a.append(1)          # 끝에 하나 붙인다
a.extend([5, 9])     # 끝에 여러 개 이어 붙인다
print(a)

a.insert(0, 2)       # 0번 자리에 끼워 넣는다
print(a)

print(a.pop())       # 끝 원소를 꺼내 돌려준다
print(a.pop(0))      # 0번 원소를 꺼내 돌려준다
print(a)

a.remove(1)          # 값이 1인 첫 원소를 지운다
print(a)
print(a.index(4), a.count(1), 5 in a)

[3, 1, 4, 1, 5, 9]
[2, 3, 1, 4, 1, 5, 9]
9
2
[3, 1, 4, 1, 5]
[3, 4, 1, 5]
1 1 True

인덱스로 읽기·쓰기a[i]O(1)위치를 바로 계산한다
끝에 넣기append(x)O(1)*끝에 붙이기만 한다
끝에서 꺼내기pop()O(1)끝에서 떼기만 한다
중간·앞에 넣기insert(i, x)O(n)i 뒤 원소를 한 칸씩 민다
중간·앞에서 빼기pop(i), del a[i]O(n)i 뒤 원소를 한 칸씩 당긴다
값으로 지우기remove(x)O(n)찾고, 당긴다
값 찾기·세기in, index, countO(n)처음부터 하나씩 비교한다
정렬sort()O(n log n)19장에서 다룬다

* append는 가끔 공간이 모자라 원소를 더 큰 곳으로 통째로 옮기지만, 평균을 내면 한 번에 O(1)이다(8장).

O(n)인 연산은 두 부류다. in처럼 값을 처음부터 훑는 연산과, insert와 pop(i)처럼 칸을 밀거나 당기는 연산이다. 리스트는 칸이 빈틈없이 붙어 있어야 해서, 중간에 하나를 넣으면 그 뒤 원소가 모두 한 칸씩 옮겨 간다.

그래서 맨 앞에서 넣고 빼는 insert(0, x)와 pop(0)이 가장 느리다. 앞쪽 작업이 잦으면 collections.deque를 쓴다(7장, 11장).

리스트 컴프리헨션

리스트 컴프리헨션(list comprehension)은 반복하면서 리스트를 채우는 코드를 식 하나로 쓰는 문법이다. [식 for 변수 in 대상 if 조건]을 "무엇을 담을지, 어디서 꺼낼지, 무엇만 남길지" 순서로 읽는다.


squares = []
for x in range(1, 6):
    squares.append(x * x)
print(squares)

print([x * x for x in range(1, 6)])          # 같은 결과를 한 줄로
print([x for x in range(10) if x % 3 == 0])  # 조건에 맞는 것만
print(['짝' if x % 2 == 0 else '홀' for x in range(4)])
print([(r, c) for r in range(2) for c in range(3)])

[1, 4, 9, 16, 25]
[1, 4, 9, 16, 25]
[0, 3, 6, 9]
['짝', '홀', '짝', '홀']
[(0, 0), (0, 1), (0, 2), (1, 0), (1, 1), (1, 2)]

if가 들어가는 자리가 두 군데라 헷갈리기 쉽다. for 뒤의 if는 거르는 조건이라 맞지 않는 값이 빠진다. for 앞의 A if 조건 else B는 값을 고르는 식이라 개수는 그대로이고, else가 꼭 있어야 한다. 이중 반복은 쓴 순서대로 바깥, 안쪽 반복이 된다.

반복문이 더 나을 때

조건이 여럿 겹치거나, 반복이 셋 이상 중첩되거나, 중간에 print 같은 다른 일을 해야 하면 평범한 for 문이 더 읽기 쉽다.

튜플과 언패킹

튜플은 바꿀 수 없는 리스트

튜플(tuple)은 한 번 만들면 바꿀 수 없는 순서 있는 묶음이다. 인덱싱, 슬라이싱, len, in은 리스트와 똑같이 쓰지만, 칸 대입이나 append처럼 내용을 바꾸는 연산은 없다.


point = (3, 5)
single = (7,)        # 원소 하나짜리 튜플은 쉼표가 필요하다
not_tuple = (7)      # 괄호만 있으면 그냥 정수 7
print(type(single).__name__, type(not_tuple).__name__)

try:
    point[0] = 10
except TypeError as e:
    print(f'{type(e).__name__}: {e}')

tuple int
TypeError: 'tuple' object does not support item assignment

튜플을 만드는 것은 괄호가 아니라 쉼표다. 괄호는 식을 묶는 데도 쓰여서 (7)은 그냥 7이다.

좌표 (r, c)나 (이름, 점수)처럼 바뀌면 안 되는 작은 묶음에 튜플을 쓴다. 리스트와 달리 딕셔너리의 키나 집합의 원소가 될 수 있다(4장).

패킹과 언패킹

여러 값을 쉼표로 묶어 튜플 하나로 만드는 것을 패킹(packing), 묶음을 풀어 여러 이름에 나눠 담는 것을 언패킹(unpacking)이라고 한다. 언패킹은 리스트나 문자열에도 된다.


pair = 3, 5          # 쉼표만 써도 튜플이다(패킹)
x, y = pair          # 하나씩 나눠 담는다(언패킹)
print(x, y)

x, y = y, x          # 두 값 바꾸기
print(x, y)

first, *rest = [1, 2, 3, 4]   # 나머지는 리스트로
print(first, rest)

3 5
5 3
1 [2, 3, 4]

x, y = y, x가 임시 변수 없이 되는 이유는 오른쪽이 먼저 계산되기 때문이다. 튜플 (5, 3)이 먼저 만들어진 뒤 왼쪽 이름들에 나눠 담긴다.

*rest 같은 별표 이름이 없으면 이름 수와 값의 수가 같아야 하고, 다르면 ValueError가 난다. 함수의 return a, b도 튜플 하나를 돌려주고 받는 쪽에서 언패킹하는 것이다.

enumerate와 zip

인덱스와 값이 함께 필요하면 range(len(a))로 돌며 a[i]를 꺼내는 대신 enumerate(a)를 쓴다. (인덱스, 값) 튜플을 차례로 내놓고, for가 그 자리에서 언패킹한다. 두 리스트를 나란히 걸을 때는 같은 자리끼리 묶어 주는 zip을 쓴다. 길이가 다르면 짧은 쪽이 끝날 때 함께 멈춘다.


fruits = ['사과', '배', '감']
prices = [1200, 3000, 800, 500]

for i, fruit in enumerate(fruits):        # (인덱스, 값)
    print(i, fruit)

for fruit, price in zip(fruits, prices):  # 짧은 쪽에서 멈춘다
    print(fruit, price)

0 사과
1 배
2 감
사과 1200
배 3000
감 800

prices의 500은 짝이 없어 조용히 버려졌다. 길이가 반드시 같아야 한다면 zip(a, b, strict=True)로 써서 다를 때 ValueError가 나게 한다.

2차원 리스트

2차원 리스트는 리스트를 원소로 갖는 리스트로, 지도나 게임판처럼 행과 열이 있는 데이터를 담는다. grid[r][c]는 r번 행 리스트를 꺼낸 뒤 그 안의 c번 칸을 읽는다. 반복 변수 _는 "이 값은 쓰지 않는다"는 관례적 표시다.


n, m = 3, 4
grid = [[0] * m for _ in range(n)]   # 행마다 새 리스트를 만든다
grid[1][2] = 7                       # 1행 2열

for row in grid:
    print(row)

[0, 0, 0, 0]
[0, 0, 7, 0]
[0, 0, 0, 0]

곱하기로 만들면 생기는 일

[[0] * m] * n으로 만들면 한 칸만 바꿨는데 모든 행이 함께 바뀐다.


bad = [[0] * 4] * 3      # 같은 행 하나를 세 번 가리킨다
bad[1][2] = 7

for row in bad:
    print(row)
print(bad[0] is bad[1])  # 0행과 1행이 같은 리스트인가?

[0, 0, 7, 0]
[0, 0, 7, 0]
[0, 0, 7, 0]
True

리스트의 칸에는 값 자체가 아니라 값을 가리키는 참조가 들어 있고(2장), *는 이 참조를 복사할 뿐이다. 그래서 [[0] * 4] * 3은 행 리스트 하나를 가리키는 참조 세 개다.

[0] * 4도 네 칸이 같은 0을 가리키지만 문제가 없다. 정수는 바꿀 수 없는 값이라, 칸에 7을 대입하면 그 칸만 7을 가리키게 되고 다른 칸은 그대로 0을 가리킨다. 컴프리헨션은 반복할 때마다 [0] * m을 새로 계산하므로 행마다 다른 리스트가 생긴다.

얕은 복사와 깊은 복사

grid.copy()나 grid[:]는 바깥 리스트만 새로 만들고 행은 원본과 함께 쓴다. 이것을 얕은 복사(shallow copy)라고 한다. 안쪽 리스트까지 모두 새로 만드는 깊은 복사(deep copy)는 copy.deepcopy가 한다.


import copy

grid = [[1, 2], [3, 4]]
shallow = grid.copy()          # 바깥 리스트만 새로 만든다
deep = copy.deepcopy(grid)     # 안쪽 리스트까지 새로 만든다

grid[0][0] = 99
print(shallow)
print(deep)

[[99, 2], [3, 4]]
[[1, 2], [3, 4]]

격자에 숫자처럼 바꿀 수 없는 값만 있다면 행마다 슬라이스하는 [row[:] for row in grid]로 충분하고, 끝까지 따라가며 복사하는 deepcopy보다 가볍다.

행과 열 뒤집기: zip(*grid)

함수를 부를 때 리스트 앞에 *를 붙이면 원소를 낱개 인자로 풀어 넘긴다. 그래서 zip(*grid)는 zip(grid[0], grid[1], ...)과 같아서 열끼리 묶인다. 행과 열을 맞바꾸는 전치(transpose)가 한 줄이다.


grid = [[1, 2, 3],
        [4, 5, 6]]

transposed = [list(col) for col in zip(*grid)]
print(transposed)

# 시계 방향 90도 회전: 행 순서를 뒤집은 뒤 전치한다
rotated = [list(row) for row in zip(*grid[::-1])]
print(rotated)

[[1, 4], [2, 5], [3, 6]]
[[4, 1], [5, 2], [6, 3]]

정렬

sort와 sorted

a.sort()는 리스트 a 자체를 정렬한다. 이렇게 원본을 직접 바꾸는 방식을 제자리(in-place) 연산이라고 한다. sorted(a)는 원본을 그대로 두고 정렬된 새 리스트를 돌려준다.


a = [3, 1, 2]
b = sorted(a)        # 새 리스트를 돌려준다. a는 그대로다
print(a, b)

result = a.sort()    # a 자체를 정렬하고 None을 돌려준다
print(a, result)

print(sorted(a, reverse=True))   # 내림차순

[3, 1, 2] [1, 2, 3]
[1, 2, 3] None
[3, 2, 1]

sort()가 None을 돌려주는 것은 원본이 바뀌었음을 분명히 하려는 설계다. sorted()는 문자열이나 튜플도 받아 리스트를 돌려준다. 둘 다 O(n log n)이고 내부 동작은 19장에서 다룬다.

key: 무엇으로 비교할지 정하기

다른 기준으로 정렬하려면 key에 함수를 넘긴다. 정렬은 원소마다 이 함수를 한 번씩 불러 비교용 값을 만들고 그 값으로 순서를 정한다. 원소 자체는 바뀌지 않는다.


words = ['banana', 'Kiwi', 'apple', 'fig']

print(sorted(words))                  # 대문자가 소문자보다 앞
print(sorted(words, key=str.lower))   # 대소문자를 무시하고
print(sorted(words, key=len))         # 길이순

['Kiwi', 'apple', 'banana', 'fig']
['apple', 'banana', 'fig', 'Kiwi']
['fig', 'Kiwi', 'apple', 'banana']

'Kiwi'가 맨 앞인 것은 대문자의 문자 코드값이 소문자보다 작기 때문이다(5장). 함수는 str.lower처럼 괄호 없이 이름만 넘긴다.

여러 기준으로 정렬하기

"나이 많은 순, 같으면 이름순"처럼 기준이 여럿이면 key가 튜플을 돌려주게 한다. 튜플은 첫 원소끼리 비교하고, 같으면 다음 원소를 비교한다. 그래서 튜플에 넣는 순서가 곧 기준의 우선순위다.


people = [('민수', 25), ('지아', 31), ('하늘', 25), ('도윤', 31)]

# 나이 내림차순, 나이가 같으면 이름 오름차순
by_age = sorted(people, key=lambda p: (-p[1], p[0]))
print(by_age)

[('도윤', 31), ('지아', 31), ('민수', 25), ('하늘', 25)]

lambda p: (-p[1], p[0])은 "p를 받아 (-p[1], p[0])을 돌려주는 이름 없는 함수"다(6장). 숫자 기준을 내림차순으로 바꾸려면 부호를 뒤집는다. -31이 -25보다 작으니 31살이 앞에 온다. 한글 이름은 코드값 순서가 곧 가나다순이다.

안정 정렬

파이썬의 정렬은 안정 정렬(stable sort)이다. 기준 값이 같은 원소끼리는 정렬 전 순서를 지킨다는 뜻이다. 덕분에 부호를 뒤집을 수 없는 "이름 내림차순" 같은 기준도 다룰 수 있다. 덜 중요한 기준부터 차례로 여러 번 정렬하면 먼저 정렬한 순서가 동점자 사이에 남는다.


people = [('민수', 25), ('지아', 31), ('하늘', 25), ('도윤', 31)]

# 나이 오름차순, 같으면 이름 내림차순: 덜 중요한 기준부터
step1 = sorted(people, key=lambda p: p[0], reverse=True)
print(step1)
print(sorted(step1, key=lambda p: p[1]))

[('하늘', 25), ('지아', 31), ('민수', 25), ('도윤', 31)]
[('하늘', 25), ('민수', 25), ('지아', 31), ('도윤', 31)]

나이가 같은 하늘과 민수는 첫 정렬의 순서를 지킨다.

자주 하는 실수

a = a.sort()

sort()는 None을 돌려주므로 a에 None이 담겨 리스트를 잃는다. 제자리 정렬은 a.sort()만 쓰고, 새 리스트가 필요하면 a = sorted(a)로 쓴다.

[[0] * m] * n으로 격자 만들기

모든 행이 같은 리스트라서 한 칸을 고치면 같은 열 전체가 바뀐다. [[0] * m for _ in range(n)]으로 만든다.

append로 리스트 붙이기

a.append([5, 9])는 리스트 [5, 9]를 원소 하나로 붙인다. 5와 9를 각각 붙이려면 a.extend([5, 9])를 쓴다.

돌고 있는 리스트에서 원소 지우기

반복문은 인덱스를 하나씩 늘려 가며 원소를 꺼낸다. 도중에 지우면 뒤 원소가 한 칸씩 당겨져 바로 다음 원소를 건너뛴다. 아래에서 2가 하나 남는 이유다. 남길 것만 골라 새 리스트를 만든다.


nums = [1, 2, 2, 3]
for x in nums:
    if x == 2:
        nums.remove(x)   # 지우는 순간 뒤 원소가 당겨진다
print(nums)

nums = [1, 2, 2, 3]
nums = [x for x in nums if x != 2]   # 남길 것만 고른다
print(nums)

[1, 2, 3]
[1, 3]

여러 기준으로 순위 매기기

퍼즐 대회 참가자 N명의 닉네임, 점수, 걸린 시간(초), 레벨이 주어진다. 아래 기준으로 순위를 매겨 1등부터 닉네임을 한 줄에 하나씩 출력하라.

  1. 점수가 높은 사람이 앞선다.
  2. 점수가 같으면 시간이 짧은 사람이 앞선다.
  3. 시간도 같으면 레벨이 높은 사람이 앞선다.
  4. 모두 같으면 닉네임이 사전순으로 앞서는 사람이 앞선다.

첫 줄에 N(1 ≤ N ≤ 100,000), 다음 N줄에 닉네임 점수 시간 레벨이 공백으로 나뉘어 주어진다. 닉네임은 서로 다른 영어 소문자 1~10자이고 나머지는 정수다. 아래는 6명의 예시와 그 순위다.

기준이 넷이어도 정렬은 한 번이면 된다. key가 우선순위 순서대로 값을 담은 튜플을 돌려주면 튜플 비교가 첫 기준부터 차례로 따져 준다.

  1. 한 사람을 (닉네임, 점수, 시간, 레벨) 튜플로 읽는다. 숫자는 꼭 int로 바꾼다. 문자열로 비교하면 '9'가 '85'보다 크다.
  2. 오름차순 기준(시간, 닉네임)은 그대로, 내림차순 기준(점수, 레벨)은 부호를 뒤집는다: (-점수, 시간, -레벨, 닉네임).
  3. 정렬한 뒤 닉네임만 모아 한 번에 출력한다.
풀이 코드 

import sys
input = sys.stdin.readline


def rank(players: list[tuple[str, int, int, int]]) -> list[str]:
    # 점수 높은 순, 시간 짧은 순, 레벨 높은 순, 닉네임 사전순
    ordered = sorted(players,
                     key=lambda p: (-p[1], p[2], -p[3], p[0]))
    return [p[0] for p in ordered]


n = int(input())
players = []
for _ in range(n):
    name, score, seconds, level = input().split()
    players.append((name, int(score), int(seconds), int(level)))

print('\n'.join(rank(players)))

복잡도
시간
O(n log n) 정렬이 대부분이다. key 튜플 비교 한 번은 일정한 시간이다.
공간
O(n) 참가자 목록, 정렬된 새 리스트, key 값을 담는다.

스스로 확인

a = [10, 20, 30, 40, 50]일 때 a[-2:]와 a[1:-1]의 결과는?

a[-2:]는 뒤에서 두 번째 칸부터 끝까지라 [40, 50]이다. a[1:-1]은 1번 칸부터 마지막 칸 바로 앞까지라 [20, 30, 40]이다.

리스트 맨 앞에서 pop(0)을 반복하면 왜 느려지는가?

꺼낼 때마다 나머지 원소를 모두 한 칸씩 당겨서 한 번에 O(n), n번이면 O(n²)이다. 이럴 때는 deque의 popleft()를 쓴다.

[[0] * 3] * 2에서 grid[0][0] = 1을 하면 왜 두 행이 함께 바뀌고, [0] * 3은 왜 괜찮은가?

* 2는 행 리스트의 참조를 복사할 뿐이라 두 행이 같은 리스트다. [0] * 3의 칸들도 같은 0을 가리키지만, 정수는 바꿀 수 없어서 대입하면 그 칸만 다른 값을 가리킨다.

key=lambda p: (-p[1], p[0])에서 -p[1]은 무슨 일을 하는가? 이름을 내림차순으로 하려면?

부호를 뒤집어 그 숫자 기준만 내림차순으로 만든다. 문자열은 그럴 수 없으니 먼저 이름으로 reverse=True 정렬한 뒤, 안정 정렬을 믿고 더 중요한 기준으로 다시 정렬한다.

정리

  1. 리스트는 0부터 세는 인덱스로 O(1)에 접근한다. 음수 인덱스는 뒤에서부터 센다.
  2. 슬라이싱 a[start:stop:step]은 stop을 포함하지 않으며, 잘라 낸 값으로 새 리스트를 만든다.
  3. 끝에서 넣고 빼면 O(1), 앞이나 중간에서 넣고 빼거나 값을 찾으면 O(n)이다.
  4. 컴프리헨션에서 for 뒤의 if는 거르고, 앞의 A if 조건 else B는 값을 고른다.
  5. 2차원 리스트는 [[0] * m for _ in range(n)]으로 만들고, 복사할 때는 행까지 복사한다.
  6. 튜플은 바꿀 수 없는 묶음이고, 언패킹, enumerate, zip과 짝을 이룬다.
  7. 여러 기준 정렬은 key가 튜플을 돌려주게 하고, 숫자 내림차순은 부호를 뒤집는다. 파이썬 정렬은 안정 정렬이다.
